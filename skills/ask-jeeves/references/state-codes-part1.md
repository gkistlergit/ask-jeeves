# Where to find each state's official statutes (part 1: Alabama to Missouri)

How to read this file:
- A cell with no marker was confirmed on 2026-10-20 by opening the official page (or the official title file or PDF) and reading the section heading or text.
- **UNVERIFIED** means it was not confirmed on an official source. The reason follows.
- **mirror** means the cite was confirmed only on an unofficial copy (FindLaw or california.public.law). That copy's own currency date is given, and the cell still counts as UNVERIFIED against the official code.
- "TOC" means the location was read in the official code's table of contents. The section text sat past WebFetch's limit.
- The non-compete column reuses the verified rows in `ask-jeeves/research/04-choice-of-law.md` Part B. Use that file for the substance.
- The machine-readable column records what WebFetch got back. HTTP codes come from `curl -sL -m 20 -o /dev/null -w '%{http_code} %{size_download}'`.
- Access was WebFetch, WebSearch and that curl test only. No browser, and no CAPTCHA or login was met or bypassed.

## Notes by state

- **Alabama.** ALISON (alaleg.gov redirects there) renders a shell with no section text. All four statute cites rest on FindLaw (current to 2024-12-30) or search results. Before quoting text, have Grant open ALISON in a browser.
- **Alaska.** akleg.gov serves curl but returns 403 to WebFetch. legis.state.ak.us fails its TLS certificate (research file). The official print code is LexisNexis's; that is UNVERIFIED here. All statute text is from FindLaw.
- **Arizona.** azleg.gov is the Legislature's drafting compilation. It reflects the law in effect on January 1 after the latest session. The official print edition is Thomson Reuters's.
- **Arkansas.** The Legislature's site says its internet version is not the official text and that the printed code controls. That is secondary, from search. The public Lexis portal cannot be read by tools.
- **California.** Use the pubinfo dump for bulk work: a MySQL-loadable export of codes and bills, documented in `pubinfo_Readme.pdf`. Individual leginfo pages are blocked (403), and california.public.law is the working mirror.
- **Colorado.** The olls.info title files are the most useful official free source. For a section deep in a big title, use the DOCX or PDF, or cite from the TOC, because WebFetch reads only the first ~480,000 characters. The trade-secret, wage and cybercrime cites are TOC-level only.
- **Connecticut.** The prdext3 host has the same content as www.cga.ct.gov. Check the 2026 Supplement page (`/2026/sup/chap_NNN.htm`) for 2025 amendments.
- **District of Columbia.** No local computer-crime statute was found under Title 22. Federal 18 U.S.C. § 1030 covers D.C. conduct.
- **Florida.** Florida has no general private-sector wage payment or final-paycheck statute. Unpaid-wage claims run through contract, § 448.08 fees, and the minimum-wage provisions (§ 448.110; Fla. Const. art. X, § 24).
- **Georgia.** The official O.C.G.A. is available free only on Lexis's portal, which tools cannot read. Every cite is from FindLaw (to 2024-03-28).
- **Hawaii.** Fetch statutes from data.capitol.hawaii.gov. The www host returns 403.
- **Illinois.** All of www.ilga.gov returned 403 on 2026-10-20, to curl as well as WebFetch. ftp.ilga.gov answers curl but fails WebFetch's certificate check, even though the research file read it earlier. Treat Illinois text as unreachable until a browser check.
- **Indiana.** The row is filled from the caller's brief and the local 2026 download. It was not re-opened in this pass.
- **Iowa.** The chapter and section PDFs are the official text and are small. Read them with the Read tool after WebFetch saves them.
- **Kentucky.** Each section is a PDF at `statute.aspx?id=`. Chapter indexes give the ids.
- **Louisiana.** No URL is built from the cite. Find the doc id with a site-restricted search, or by section on Law.aspx.
- **Maryland.** The official Annotated Code is a commercial publication. The publisher's name is UNVERIFIED, and the MGA site does not claim to be official.
- **Mississippi.** The official free text is on Lexis only. The Secretary of State page that used to link to it now returns 404. Statute cites are from FindLaw (to 2025-01-01).
- **Missouri.** The online RSMo is labeled unofficial. Certified text is in the printed RSMo and its supplements.
