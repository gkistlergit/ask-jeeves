Each row was checked on 2026-10-20 with WebFetch, plus `curl -sL -m 20 -o /dev/null -w '%{http_code} %{size_download}'` for reachability. No browser was used. No CAPTCHA, bot check or login was bypassed.

**Non-compete cells reuse Part B of `ask-jeeves/research/04-choice-of-law.md`** (verified 2026-10-20) unless the cell says it was re-opened here. Every other statute cell was checked by opening the section, chapter or session law named in it.

**How to read the table:**
- **"text 200"** means WebFetch got statute text back and curl returned HTTP 200.
- **"PDF + PDFKit"** means the official file is a compressed PDF. WebFetch reads only its bookmarks, so the text was pulled from the file WebFetch saved, using macOS PDFKit (`PDFDocument(url:).string`).
- **"UTSA"** marks a chapter that names itself the Uniform Trade Secrets Act.
- **UNVERIFIED** gives the reason in the same cell.

## Notes by state

**South Carolina (main state):**
- **Trade Secrets Act:** Title 39 ch. 8 (§§ 39-8-10 to -130) is confirmed. § 39-8-10 reads that the chapter "may be cited as the 'South Carolina Trade Secrets Act'". The definition is § 39-8-20(5).
- **Payment of Wages:** Title 41 ch. 10 (§§ 41-10-10 to -110) is confirmed. The chapter is titled "Payment of Wages" and has no short-title section, so "South Carolina Payment of Wages Act" is the conventional name, not statutory text.
- **Computer Crime Act:** Title 16 ch. 16 (§§ 16-16-10 to -40) is confirmed. The chapter heading is "Computer Crime Act".
- **No general non-compete statute.** The Title 41 ch. 1 listing (41-1-10 to -130) has none. A site search of scstatehouse.gov for "covenant not to compete" returned only bills: H.3273 (2025–26), S.3332, H.3335 and H.5242, all proposing a nonprofit ban as § 41-1-130/-140, and none enacted. Part B also records H.4767 (physicians), which passed the House only, and S.46, which died. Non-competes rest on case law: *Stonhard* (2005), *Poynter* (2010), *Fay* (Ct. App. 2017).
- **Downloads:** Word only, one chapter at a time. Each title page (`/code/titleN.php`) links "HTML" and "Word" per chapter, and the Word link is `/getfile.php?TYPE=CODEOFLAWS&TITLE=T&CHAPTER=C`. There is no whole-title or whole-code file:
  - `getfile.php` without CHAPTER returns a 14-byte HTML reply.
  - No PDF, RTF or ZIP links appear on `statmast.php`.
  - The full-text search is `/query.php`.

**New Jersey:** The browse interface can't be machine-read, but the whole statute set is a public weekday-built ZIP (`STATUTES-TEXT.zip`, 20.4 MB). It was not downloaded here: the task allowed reachability tests only, and downloading needs Grant's approval. To cite a section without the ZIP, open the P.L. chapter on pub.njleg.gov; it gives the "C." codification cite for each section.

**New Mexico:** NMOneSource is the official compilation, and it returned 403 to WebFetch (as in Part B). For current wording, use nmlegis.gov bill texts, which quote existing law with the "(being Laws …, as amended)" history.

**New York:** There is no official free code. The Senate's Open Legislation data (LBDC) is the standard public source. NY is the only state with no UTSA (Chambers 2026, secondary), so trade-secret claims are common law plus the federal DTSA.

**North Carolina:** The Trade Secrets Protection Act (G.S. 66-152 et seq.) is NC's own statute, not a UTSA adoption by name.

**Oklahoma:** OSCN shows a Cloudflare Turnstile verification page to automated requests. It was not bypassed. Use the Legislature's per-title PDF or RTF files instead.

**Pennsylvania:** HTML pages come back empty to WebFetch, and curl gets 403. Use `txtType=PDF` and extract the text locally, or use `txtType=DOC`.

**Tennessee:** The official code is LexisNexis's. Its free portal gives an automated client nothing. Statute cells for trade secrets and computer crime rest on secondary sources. For verified text, use enrolled public chapters on publications.tnsosfiles.com (403 here) or a tncourts.gov opinion quoting the section.

**Texas:** The statutes site is now a single-page app, so all legacy `Docs/` URLs return the same shell. Confirm sections through enrolled bill texts on capitol.texas.gov/tlodocs, which are readable.

**Utah:**
- To read a current section, you need its version id (`_{start}{end}` in the filename), and only the JS loader reveals it.
- `_1800010118000101` is the base version. For § 34-28-3 it is marked "Superseded 5/13/2014", so do not assume it is current.
- Search results surface older versioned files; a newer version may exist.

**Wisconsin:** The site returned HTTP 429 after about three quick requests. Space out fetches.
